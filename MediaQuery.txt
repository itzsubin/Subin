For responsive design we use media query:
Usually for Mobile Phone it ranges from 320px to 600px.
For tables or ipad it ranges from 600px to 1024px.
For desktop it ranges from 1024px to 1440px. 


For general Tablet:
@media only screen and (min-width: 768px) and (max-width: 1024px) {
  /* Tablets (portrait & landscape) */
}
For Ipad portrait
 @media only screen and (min-width: 834px) and (max-width: 1210px) and (orientation: portrait) {
  /* iPads in portrait */
}
For Ipad landscape
@media only screen and (min-width: 768px) and (max-width: 820px) and (orientation: portrait) {
  /* iPads in portrait */
}

For Iphone in general 
@media only-screen (max-width: 480px){

}

@media only screen and (max-width: 844px) and (orientation: landscape) {
  /* iPhones in landscape orientation */
}

For Touch Screen and effetcive in responsive design use this query:
@media only screen and (hover: none) and (pointer: coarse) and (max-width: 768px) {
  /* Styles for touch devices with small screens (like phones & tablets) */
}

Only screen means for viewing in laptop, phone and tablet, its not for printing.
