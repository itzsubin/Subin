                   My Portfolio Website

A modern, responsive portfolio website built with React, HTML5, CSS3, and JavaScript to showcase my skills, projects, and professional journey.


Features

Modern UI/UX - Clean, responsive design with smooth animations

Fully Responsive - Optimized for all devices (mobile, tablet, desktop)

Fast Performance - Built with React for optimal loading speeds

Interactive Elements - Engaging user interactions and animations

Contact Form - Integrated Web3Forms for seamless communication

Dark/Light Mode - Toggle between themes

SEO Optimized - Proper meta tags and structured data

Prerequisites

Node.js (version 14 or higher)
npm or yarn

Environment Setup
Create a .env file in the root directory:
REACT_APP_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key_here
